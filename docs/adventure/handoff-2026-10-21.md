## End-to-end run (Task 21, local)

API on :5002 against a fresh DB `pokemontcg_dev_adventure` (all migrations, in the `ptcg-dev-db`
container), frontend on :3002 with `NEXT_PUBLIC_API_URL=http://localhost:5002`. Test users
`aventura1…5@test.local` / `Aventura123!` (local DB only). Battles driven by a socket bot
(scratchpad `e2e-bot.mjs`, greedy: Basics, evolve, Energy, strongest attack; no Trainers) and by
Playwright clicks on the real pages.

Checked and working:
- Entry on /play, adventure screen, new run (3 starters, normal/hard), map, run bar, deck editor
  (treasure cards added, 20–40 limits enforced by the API: 60 cards → 422).
- Battles on the multiplayer board against the server-run AI: setup, the AI's turns, coins,
  prizes; the battle's rules shown in the room (battle 7: 1 prize, Metapods give none, the
  rival's opening board).
- Defeat → heart lost, same battle again; surrender costs a heart; 0 hearts → run lost.
- Victory → treasure offer (3 options; major treasures after battle 5); card treasures that would
  pass 40 cards are left out of the offer.
- Leaving mid-battle and coming back ("Volver a la batalla"): same state. API restarted mid-battle:
  the room is rebuilt from the run, same turn and hand, the game goes on.
- Winning battle 10: run `won`, card back `cardback-bosque-verde` granted, progress saved,
  end screen, achievements claimable and claimed from the profile (Aventura group).
- Hard: battle 10's rival leads with the starter that beats yours (Charmander→Squirtle,
  Squirtle→Bulbasaur, Bulbasaur→Charmander).

Found and fixed: the opening log line read "X roba 7 cartas y colocas 3 premios" (the API only
rewrites it for 6 Prizes; the frontend fallback missed "colocas"). Fixed in the frontend's
`EventLogger.tsx`; it also fixed the same line in single player.

Not covered: a full 10-battle run won with the starter decks (the bot doesn't play Trainers, so it
stalls around battles 3–5; battles 5 and 10 were reached by moving test runs forward in the local
DB and giving one a strong deck). Balance is for the owner's play test.

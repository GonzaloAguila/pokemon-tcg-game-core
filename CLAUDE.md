# CLAUDE.md — @gonzaloaguila/game-core

Pure TypeScript engine for **Nostalgic TCG** (classic Pokémon TCG: Base Set 102 + Jungle 48 + Fossil 47 + Team Rocket 66 + Gym Heroes cards; see `docs/fossil-team-rocket-design.md` and `docs/superpowers/specs/2026-10-16-gym-heroes-design.md`). Holds `GameState`, attacks/effects, status conditions, Pokémon Powers, trainers, AI, card catalogs and theme decks. No React, no browser APIs, no Node-only APIs.

## Consumers (sibling repos under `D:/Proyectos/`)

| Repo | How it consumes this package |
|------|------------------------------|
| `pokemon-tcg` (Next.js frontend) | GitHub Packages, exact version. Runs the engine in the browser for single-player vs AI. |
| `pokemon-tcg-api` (Express + Socket.io) | GitHub Packages, exact version. Authoritative for multiplayer. |

Both must pin the SAME version, otherwise single-player and multiplayer run different rules. After changing the engine: build, `npm version patch`, publish, then bump both consumers and redeploy the API.

## Commands

```bash
npm run build      # tsc && tsc-alias → dist/ (rewrites @/ aliases)
npm run dev        # tsc --watch
npx tsc --noEmit   # type check
npm test           # vitest (test/**, card-scenario helpers in test/helpers/state.ts)
npm run typecheck:test
npm run simulate -- --games 500 --seed 1 --sets base-set,jungle --policy all   # bot fuzzer (tsx)
npm run simulate -- --games 1000 --sets base-set,jungle,fossil --stats --coverage fossil   # + action counts and coverage of a set
npm run simulate -- --games 1000 --sets team-rocket --stats   # coverage includes on-play powers (powerChoice <name>)
npm run simulate -- --games 1500 --policy explore,random --decks lucky-duel --check-mutation   # Lucky Duel tables (random Basic + deck per side)
npm run simulate -- --games 1000 --policy smart:legacy,legacy:smart --decks theme   # AI strength: smart (= greedy, the shipped AI) vs legacy (the old greedy script), both seats; --decks random | random-mix | theme
npm run simulate -- --games 3000 --policy explore,explore:greedy,explore:random --decks random-mix --stats   # explorer: steers to the least-used cards/attacks (~100% coverage); adaptive, so replay = same --seed with --games up to the failing game (printed); --check-mutation also fails on input mutation
npm run check-images -- --set fossil   # HEAD every image URL of a set (network)
npm version patch && npm publish   # GitHub Packages; prepublishOnly builds; needs auth with write:packages
```

`npm run lint` is declared but eslint isn't installed. Write a failing card-scenario test first for any rule change (`makeState`, `inPlay`, `deepFreeze`, `armedFor` helpers — attacks are only legal when paid, so give attackers Energy or wrap them in `armedFor`). npm 10 can crash adding devDependencies — use `npx npm@11 install -D …`. After any rule change also run `npm run simulate` (0 failures expected; a failure prints the seed to replay with `--games 1 --seed N`).

Must stay `"module": "CommonJS"` in tsconfig (ESNext output breaks Node with `ERR_UNSUPPORTED_DIR_IMPORT`). `dist/` is gitignored and is the only thing published.

## Layout

- `src/index.ts` — the public API. Anything consumers use must be exported here (also re-exported via `src/domain/match/index.ts` for some engine functions).
- `src/lib/gameState.ts` — the engine (~5k lines): `GameState`/`PokemonInPlay` types, setup/mulligan, `executeAttack` (+ coin plans), `endTurn`, retreat (+ Sinkhole coins), evolution, prizes, Knock Outs (`checkKnockouts`), pending-state resolvers, Energy typing (`energyProvidesType`, `getEnergyValue`, `energyCardLabel`). `src/lib/attackChoices.ts` — the generic pending attack choice (`resolveAttackChoice`, `dealChosenTargetDamage`). `src/lib/powerChoices.ts` — "when you play it from your hand" powers (`pendingPowerChoice`, `resolvePowerChoice`, `ON_PLAY_POWERS`).
- `src/domain/cards/` — card types, factories, guards (`isPlayableAsBasic`), `in-play.ts` (Trainers played as Basics: `toInPlayCard`, `cardsLeavingPlay`, `givesPrizeWhenKnockedOut`). `catalog/` — `sets.ts` (**set registry**: `CARD_SETS`, `ALL_CARDS`, `findCardById`, `findCardDefinition(set, number)`, `findCardByName`, `getCardImageUrl`), `base-set.ts`, `jungle.ts`, `fossil.ts`, `image-urls.ts` (pkmncards.com slugs; `scripts/check-images.ts` checks them). `decks/` — theme decks + resolution.
- `src/domain/lucky-duel/` — the Lucky Duel table type (`state.gameMode === "lucky-duel"`, spec `docs/superpowers/specs/2026-10-18-lucky-duel-design.md`): `mode.ts` `isLuckyDuel` (no runtime imports: the engine core uses it), `rules.ts` (`LUCKY_DUEL_EXCLUDED_TRAINERS` with reasons, line-dependent Trainers, the power / attack / Trainer blockers), `deck.ts` (`drawLuckyDuel(rng)`, `buildLuckyDuelDeck`: the line + 6 extra Pokémon of the two colours that can never enter play (`lineFamily` keeps out anything that evolves onto the line) + 24 Energy + Trainers, `initializeLuckyDuelGame(p1, p2, rng)`: Actives placed face down, `luckyDuelRevealed` flips in `startPlayingPhase`). Benches locked through `maxBenchSize` (0), no Prizes, draws by `settleLuckyDuelDraw` (end of `checkKnockouts`, endTurn checkup, Destiny Bond).
- `src/domain/board/` — engine-owned board actions: `playBasicPokemon`, `attachEnergyCard` (Rain Dance, `ENERGY_ATTACH_EFFECTS` hook — `special-energy.ts`: Rainbow / Full Heal / Potion Energy), `evolvePokemonCard` (then the on-play power), `discardFromPlay` (Mysterious Fossil), their `canX`, `getTurnActionBlocker`, `getEvolutionBlocker` (Prehistoric Power), `getTrainerBlocker` (Headache, Hay Fever), `swapSides`, `findInPlay`.
- `src/domain/effects/` — **card effect registry**: `TRAINER_EFFECTS` (by card name) and `POWER_EFFECTS` (by power name) as `CardEffectDef { canUse, getSteps, coinFlips?, resolve }`, generic entry points `canPlayTrainerCard/getTrainerSteps/getTrainerCoinFlips/playTrainerCard` and `canUsePokemonPower/getPowerSteps/getPowerCoinFlips/usePokemonPower`. Selection meanings are tabled at the top of `effects/trainers.ts` and `effects/powers.ts`.
- `src/domain/trainers/index.ts` — the per-trainer `canPlayX` / `playX` the registry wraps; `trainers/attached.ts` — Trainers attached to a Pokémon until a trigger (Gym Heroes' Charity, Sabrina's ESP) in `PokemonInPlay.attachedTrainers`: `attachTrainer`, `attachedTrainerNamed`; endTurn returns / discards the ending side's ones before the between-turns checkup (Charity → hand, ESP → discard pile); they leave play with their Pokémon (`cardsLeavingPlay`). Gym Challenge: Brock's Protection stays until its Pokémon leaves play (`energyRemovalBlocked(state, p, "opponent")`: every opponent attack / Trainer path taking an attached Energy card skips it); Koga's Ninja Trick stays while its Pokémon is the Active (checkKnockouts' sweep discards it from the Bench). `powers/index.ts` — Pokémon Powers (`isPowerActive`, Toxic Gas `getToxicGasSource`, Transform `getEffectivePokemonCard` / `getEffectiveHp`, `isHandRevealed`, Kabuto Armor `applyDamageHalving`, per-power functions). `status/` — status helpers. `ai/` — `smart.ts` (the AI: `decideOpponentTurn` / `decideOpponentSetup` / `decideOpponentPromotion`; plans on `knowledge.ts` `knowledgeView` — hidden cards replaced, see fair play below), `evaluate.ts` (expected damage over every coin outcome, next-turn Knock Out threats, `evaluateBoard`), `choices.ts` (which Pokémon to promote / drag up; also the engine's automatic promotion of the AI in single-player), `legacy.ts` (the old greedy script, simulator baseline only), `actions.ts` (board actions through the engine, AI log rewording), `executor.ts` (apply; trainers and powers via the registry, the AI flips their coins; Metronome / Conversion choices on the attack action; `finishAIAttackAfterReaction` completes an AI attack the human paused with an answer), `cardEffects.ts` (rules for the Fossil / Team Rocket / Gym Heroes Trainers and simple powers, Stadiums `planStadium` / `stadiumValue`, and how the AI answers Trainer / power steps), `attackAnswers.ts` (`answerAttackChoiceForAI(attackerView)`: the AI's answer to a pending attack choice whichever side it is — its own Fairy Power / Magic Pollen / Sleight of Hand / ESP / Charity, the defender's Flee / Bench Guard / forced switch; consumers call it when the AI answers the human's attack), `pending.ts` (the AI answers its own attack's choices; `answerStepForAI`).
- `src/domain/simulation/` — headless bot games (`playAIGame`, greedy (= smart) / legacy / randomLegal / explore policies, theme decks (`--decks theme`: the classic ones and the Gym Leader decks), from half the turn cap (`stalemateTurn`) the runner ends every turn so a stalemate (Psychic Exchange refills the deck) ends by deck-out, seeded RNG, random and random-mix decks, per-state invariants in `invariants.ts`, whole-game rules in `rules.ts`: prizes = Knock Outs, checkup damage, one retreat / one Energy per turn); `scripts/simulate.ts` is the CLI.
- `src/shared/errors.ts` — `IllegalActionError` / `assertLegal`.
- `src/domain/constants/enums.ts` — `as const` enums (`EnergyType`, `AttackEffectType`, `PokemonPowerType`, `GamePhase`, …). `PokemonStage` values are `"basic" | "stage-1" | "stage-2"`.
- `src/domain/match/types.ts` re-exports the `GameState` types of `gameState.ts` (single definition).

## Model and conventions

- State is relative: `player*` fields vs `opponent*` fields, plus `isPlayerTurn`. To act as the other side, callers swap perspective (AI executor and API both do this).
- Every action is `(state, ...args) => newState`. Never mutate the input — copy arrays before `splice`/`push`.
- Validate with `canX()` (returns a Spanish reason or `null`) before calling the action. The newer entry points enforce it themselves and **throw `IllegalActionError`** (with the same reason) when called anyway: board actions, `playTrainerCard`, `usePokemonPower`, `executeAttack` (`canExecuteAttack`: turn, statuses, Leer, Energy cost, requirements, one attack per turn — no first-turn ban, classic 1999 rules) and `executeMetronome` (`canExecuteMetronome`). Older functions (`executeRetreat`, the legacy `playX`) still return the state with an info event.
- Turn bookkeeping: `attackedThisTurn` (set by an attack or a failed confused attack) and `checkupDoneOnTurn` (endTurn paused for a prize/promotion after the between-turns checkup; the next endTurn won't repeat the checkup) both block normal actions and are cleared when the turn passes.
- Card behavior is data in the catalog (`attacks[].effects[]` with `AttackEffectType`); the interpreter is the effects loop in `executeAttack`.
- Coins are flipped by the caller (the server is authoritative in multiplayer) and passed in: `resolveConfusionFlip(state, heads)` before ANY attack (Metronome and Conversion included), `executeAttack(state, i, { coinResults })` with the coins of `getAttackCoinPlan(state, i)` (Metronome: pass the copied `Attack`), built with `flipAttackCoins(plan, flip)`. Layout: [Sand-attack/Smokescreen coin (tails: the attack does nothing)] + [power coins, `plan.power` (absent = 0), flipped by the attacker: Rebellion of a working Misty's Gyarados, 2 coins, also while Confused; both tails: the attack does nothing (no Energy discard), Gyarados and its cards are shuffled into the deck, no Prize, its owner promotes] + the attack's own coins (a fixed number, or `"untilTails"`: a run ending in the first tails, Stone Barrage; `plan.attackFlipper === "opponent"` when the defending player flips them: Knock Down, Bench Manipulation) + [Stadium coin: Vermilion City Gym, only when the attacker opts in with `{ vermilionCoin: true }` on both `getAttackCoinPlan` and `executeAttack` (`canUseVermilionCoin(state, i)`), `plan.stadium`] + [defender coin, LAST: Transparency of a Defending Haunter, or Final Beam of a Defending Dark Gyarados (used only if the attack Knocks it Out), Shadow Images, Crosscounter, or Pollen Defense of a Defending Erika's Vileplume (used only if the attack damages it), Fortitude of a Defending Giovanni's Machamp (used only if the attack's damage would Knock it Out; heads: 10 HP left), Energy Drain of a Defending Koga's Muk (used only if damaged, Knock Out included; heads: its owner picks 1 Energy card of the attacker to discard — a `pendingAttackChoice` `DiscardAttackerEnergy` step, chooser "opponent"), Shock Blast of a Defending Lt. Surge's Electrode (used only if damaged; tails: 20 to each Active after the attack, no W/R) — all flipped by the defending player]. `getAttackCoinFlipCount` is the total for fixed plans only. All coin effects of one attack share the same coins; coin damage is part of the base damage (before weakness/resistance). Trainers/powers: `getTrainerCoinFlips`/`getPowerCoinFlips` coins are flipped before the first step and passed to `getXSteps` and `playTrainerCard`/`usePokemonPower` as `{ coinResults }` (Digger: `"untilTails"`, coin i flipped by you for even i, by the opponent for odd i); a Trainer whose coin comes after its choices (Blaine's Gamble: "discard…, then flip") asks 0 coins before its steps and its coins once they are answered — callers that flipped none ask again with `getTrainerCoinFlips(state, cardId, selections)`. Who flips each coin, for captions: `getTrainerCoinFlippers(state, cardId, count)` / `getPowerCoinFlippers(state, pokemonId, count)` → `("self" | "opponent")[]` (declared per effect with `CardEffectDef.coinFlipper(index)`; never key it by card name). Retreat: `executeRetreat(state, ids, i, { coinResults })` with `getRetreatCoinFlips(state)` coins (Sinkhole; omitted = the engine flips). Sabrina's ESP's re-flip (an attack choice answer): `getAttackChoiceCoinPlan(state, selection)` → `flipAttackCoins(plan, flip)` → `resolveAttackChoice(state, selection, { coinResults })` (only the attack's own coins; the engine throws without them).
- Pokémon Powers: every "does this power work now?" check goes through `isPowerActive(state, pokemon)` (has power, not Asleep/Confused/Paralyzed, not suppressed by `state.powersSuppressed` or a working Toxic Gas; Thick Skinned ignores statuses).
- Transform (Ditto): the engine reads Pokémon data through `getEffectivePokemonCard(state, pokemon)` wherever it matters (attacks, types, W/R, HP, retreat); never store the effective card. HP can drop when the other Active changes, so `checkKnockouts` (state-based Knock Outs, automatic Prizes) runs after attacks, trainers/powers, retreat, evolution, promotion and around the endTurn checkup.
- Trainers played as Basics (`playsAsBasic: { hp }`: Mysterious Fossil, Clefairy Doll) are a Pokémon in play (`toInPlayCard`, `trainerCard` keeps the Trainer) and the Trainer again everywhere else: any code moving in-play cards to a pile must use `cardsLeavingPlay` / `cardOutOfPlay`, and Prizes check `givesPrizeWhenKnockedOut`.
- Multi-step effects set a pending flag (`pendingForceSwitch`, `pendingSelfSwitch`, `pendingDeckSearch`, `pendingBenchDamageSelection`, `pendingAttackChoice`, `pendingPowerChoice`, `pendingTypeShift`, `pendingPeek`); `endTurn()` must refuse to advance while one is set, the UI shows a modal, a resolver clears it (resolvers take `{ skipEndTurn }`), and the AI (`ai/pending.ts`) and the simulator must resolve it. Powers asked in the middle of an attack (Gym Heroes' Flee, Bench Guard) and the questions of Trainers attached to the attacker (Sabrina's ESP: "¿Volver a lanzar las monedas?" once the attack's own coins are known — answer `ESP_REFLIP_OPTION` with new coins, see coins above; Charity: by how much to reduce the damage to the Defending Pokémon, asked once that damage is known, before Flee; Koga's Ninja Trick: the PRE-ATTACK reaction, `answers: "preAttack"`, see below) are a `pendingAttackChoice` with `reaction` (`reaction.answers` = the `AttackReactions` entry it fills; `powerType` only for powers): the attack (or the Bench damage / attack choice step) returned its input untouched, and `resolveAttackChoice` runs it again with the answer (`ExecuteAttackOptions.reactions`). Koga's Ninja Trick (on the Defending Pokémon, Bench not empty; `getAttackPreReaction(state, i | copiedAttack)`) is asked after the Confusion flip and before ANY coin: executeAttack / executeMetronome with `{ coinResults }` ignore the coins and pause; callers (the MP server) flip nothing until the answer, then flip `getAttackChoiceCoinPlan(state, selection)` (the whole attack's plan against the Pokémon that will defend; null = no coins) and pass them to `resolveAttackChoice(state, selection, { coinResults })`, which switches (`applyNinjaTrickSwitch`, Ninja Trick discarded) and runs the attack. While such a reaction is pending the attack hasn't happened: `attackedThisTurn` stays false and the board is unchanged, so an MP server must not treat the attack as done (no "attack resolved" handling, no endTurn) until the answer resumed it. Single-player: after the human answers a choice of the AI's attack (reaction or Terror Strike; `resolveAttackChoice` on the AI's view with `{ skipEndTurn: true }`, swapped back), call `finishAIAttackAfterReaction(humanView)` (ai/executor.ts): it runs the executor's post-attack step — the AI answers its own choices raised after the resume (its Bench Guard on its own Bench...), promotes after its own Knock Out, rewords the log for the human and ends the turn unless a Prize / promotion / another answer is pending (the AI's Prize is still taken by the consumer, as after any AI attack). New attack choices use `pendingAttackChoice` (a `SelectionStep` with `chooser`, answered with `resolveAttackChoice` on the attacking side's view), not a new flag; powers played from the hand use `pendingPowerChoice` (`resolvePowerChoice`, also on the acting side's view). Narrow Gym's discard-down is `pendingBenchTrim` (a queue of `{ side, keep }`, swapped by `swapSides`; `getBenchTrimStep` / `resolveBenchTrim` on either view; the AI: `resolveBenchTrimForAI`). Misty's Duel is `pendingDuel` (domain/duel/rps.ts: each side picks with `submitDuelPick` on any view, `maskDuelFor` hides the other pick until both are in (`playerPicked` / `opponentPicked` say who picked), a tie replays the round, a decisive one sets `lastDuel` `{ picks, winner }` until endTurn; both swapped by `swapSides`; SP: `submitDuelPickVsAI`; the AI plays it only with `otherPlayerDuels`). `endTurn` also waits while either side must promote.
- Attack indices (Recall, Gym Heroes): every entry point that takes an attack index (`canExecuteAttack`, `canUseAttack` with the state, `getAttackCoinPlan`, `executeAttack`, `canUseVermilionCoin`, `getAttackDiscardRequirement` with the state, the resume of a paused attack) reads `getAvailableAttacks(state, pokemon)` → `{ attack, fromCard, index, recalled }[]`: the Active's own attacks first with their printed indices (a transformed Ditto: the copied card's), then — only while `state.recallActiveOnTurn === state.turnNumber` and `pokemon` is the Active of the side whose turn it is — the attacks of the cards under it (`previousEvolutions` order, Basic first) at indices `own.length + k`. Existing indices never change; a paused attack resumes with the same index on the untouched state (the mark is still there). List attacks with `getAvailableAttacks`, never `card.attacks`, in anything that picks an attack to use (AI, simulator, consumers' attack pickers); the simulator labels recalled attacks `X: Y (Recall: Z)` (`--stats`: "attack through Recall").
- Energy: check types with `energyProvidesType(card, type)` (Rainbow Energy is every basic type in play, one at a time; Buzzap its chosen type), count units with `getEnergyValue` (`provides` on the card data; DCE 2). Outside play Rainbow is not a basic Energy (`isBasicEnergy`). Only basic Energy is unlimited in a deck (`isLimitedInDeck`).
- Hidden information: `isHandRevealed(state, side)` (Clairvoyance), `arePrizesRevealed(state, side)` (Here Comes Team Rocket!: `state.prizesFaceUp`), and a step with `reveals: "opponentHand"` (Rocket's Sneak Attack) must be built from the unmasked state by the server. Tickling Machine's `state.setAsideHands` (`{ side, cards, returnsAfterTurn }[]`, domain/trainers/set-aside.ts: out of the hand until endTurn returns them at the end of that side's turn `returnsAfterTurn`, before the checkup) is hidden from BOTH players (mask the cards, keep counts; `setAsideCards(state, side)`); every perspective swap must flip it (`swapSetAsideHands`; board `swapSides` does).
- Log meaningful actions to `state.events` via `createGameEvent()`. Event text is Spanish; coin results use `[coin:heads]` / `[coin:tails]` tokens. A line that shows cards to both players (Lass's hands, the cards a SearchDeckChoice finds) passes them as `createGameEvent(msg, type, toLogCards(cards))` → `event.cards: LogCard[]` (`{ name, imageUrl }`, never an id); only put cards there that the rules reveal.
- Deck searches show the whole deck: every step picking cards from its player's deck builds `options` / `cards` with `wholeDeckChoice(deck, canTake)` (domain/effects/deck-search.ts: takeable cards first in deck order, the rest disabled, sorted by name); min/max selections stay about the takeable cards.
- Event perspective: a function writes its events for the view it ran on, and consumers rewrite the relative forms (API `neutralizeEvents` → "Jugador 1/2", AI `toOpponentMessage` → "Rival …"). Base Set / Jungle lines use second person for that side ("Jugaste", "Robaste", "tu mazo", "tu banca") and "el rival" for the other. Since Fossil / Team Rocket the only relative forms allowed in new lines are the leading ones every consumer rewrites ("Jugaste X", "Robaste N cartas", "Descartaste X", "Debes elegir un Pokémon de tu banca para continuar"); everything else is perspective-free — name the Pokémon / cards and say "el atacante", "el defensor", "quien lo jugó", "el otro jugador" (never "tu"/"Tu rival"/"del rival", never "su" and "tu" for the same player, never a step's description copied into the log). Choice resolutions (attack, power and Trainer steps, possibly answered by the other side) must be perspective-free. `test/event-perspective.test.ts` checks it.
- Selection steps: `title` / `description` always speak to the card's player / attacker (the side whose view built the step). A step with `chooser: "opponent"` also carries `answererTitle?` / `answererDescription?` worded for the player who answers it; show it to them with `stepForAnswerer(step)` (the waiting player keeps `description`). Every step another player answers, and every mid-attack question, carries `defaultSelection` — a valid, harmless answer for the MP answer clock (Erika "0", Treaty "draw", Challenge! "decline", Flee / Bench Guard none, ESP "keep", Charity "0"…); a new such step must set one (`test/default-selection.test.ts`).
- Gym Heroes owners: "a Pokémon with Brock in its name" = `hasOwner(card, "Brock")` / `ownerOf(card)` (domain/cards/owner.ts, the `Brock's ` name prefix; ASCII apostrophe). Stadiums: `state.stadium` `{ card, playedBy }` (one at a time, shared), rules only through the hooks of `domain/stadiums/rules.ts` (see How to add… a Stadium). Recall: see attack indices above. Misty's Duel: `pendingDuel` (see pending states). Tickling Machine: `setAsideHands` (see hidden information).
- Gym Challenge (released in 0.9.0). **Live HP**: Giant Growth (`PokemonInPlay.hpOverride`, cleared on the Bench), Gaseous Form (+10 per Psychic Energy card) and Shapeshift change HP inside `getEffectivePokemonCard` (`hp`), so read HP only with `getEffectiveHp(state, p)` / the effective card (AI included) — losing HP below the damage is a Knock Out with a Prize at the next `checkKnockouts`. **Shapeshift** (Brock's Ninetales): the attached Evolution card lives in `attachedTrainers` (`getShapeshiftCard`), the effective card takes its name / types / HP / W/R / retreat / attacks (`shapeshiftedFrom` = its own card); broken ones are discarded first thing in checkKnockouts. **Psylink** (Sabrina's Alakazam): `getAvailableAttacks` lists own → Recall → the other Psychic Pokémon's effective own attacks (`psylink: true`); same index rules as Recall. **Borrowed Trainers** (Sabrina's Psychic Control heads → `pendingBorrowedTrainer`; Chaos Gym's accepted offer): every Trainer entry point runs on `trainerView` (a copy of the card in the hand) and strips the copy after; the card never leaves its owner's discard pile; `playTrainerCard(..., { borrowedFromOpponentDiscard: true })`, `declineBorrowedTrainer`. **Hidden cards**: Misty's Wish's Prize, the Quiz cards and Surprise's card appear only in a step's `cards` with `reveals` (`"ownPrizes"`, `"opponentHand"`, `"opponentCards"`) and are never named in the log; Lt. Surge's Secret Plan's face-down Pokémon is a placeholder card (`FACE_DOWN_NAME`, hp 0, real card in `pokemon.faceDownCard`) that flips by state (`revealFaceDownCards`, first in checkKnockouts) or by its owner (`canFlipFaceDown` / `flipFaceDown`); KO predicates skip it; `maskFaceDownFor(state, viewer)` hides it from the other side (the AI's `knowledgeView` uses it; an MP server must too). Fortitude / Energy Drain flip only for the ACTIVE Defending Pokémon (known gap, docs/card-doubts.md). AI: `answerChaosGymOfferForAI` accepts and plays an offer its planners would play (`wantsChaosGymOffer`), Fuchsia / Saffron City Gym actions (`planFuchsiaCityGym` alone, `planStadiumAction`), no weak Basics onto the Bench under Rocket's Minefield Gym.
- Card IDs: `{set-slug}-{3-digit-number}-{slug-name}` (`base-set-004-charizard`, `jungle-007-nidoqueen`). Source data: api.pokemontcg.io (`base1`, `base2` = Jungle, `base3` = Fossil, `base5` = Team Rocket).
- Any lookup by card must search all sets: use the registry (`ALL_CARDS`, `findCardDefinition`, `findCardByName`), never a hand-written `[...baseSetCards, ...jungleCards]`.

## How to add…

- **A set**: catalog file `src/domain/catalog/<set>.ts` (ids via `makeCardId`), its value in the `CardSet` enum, one entry in `CARD_SETS` (id, code, release date, printed total, image URL builder), image URL check. Everything else (lookups, decks, simulator `--sets`) follows the registry. While its effects are being built, mark the set `inDevelopment: true` (`CardSetInfo`): it stays out of the simulator's default sets and Lucky Duel pools, and its unimplemented Trainers go in `UNSUPPORTED_TRAINERS` (the registry coverage test checks the rest); remove the flag at release time, once the API and frontend are ready (and the catalog test's in-development assertions).
- **A Trainer**: a `CardEffectDef` in `TRAINER_EFFECTS` (key = card name): `canUse` (Spanish reason), `getSteps` (one `SelectionStep` per question; `minSelections` for "up to"; a step the opponent answers gets `chooser: "opponent"` + `answererDescription`), `coinFlips` if it flips (`coinFlipper` when the opponent flips some), `resolve` (trust the selections: the entry point validated them against your steps). A Trainer that ends the turn (Minion of Team Rocket's tails) calls `endTurn` itself unless `{ skipEndTurn: true }` (then it returns `attackedThisTurn` set and the caller ends the turn; the AI executor does so after swapping back). Add a scenario test through `playTrainerCard`; the coverage test fails until every catalog Trainer has an entry (or is in `UNSUPPORTED_TRAINERS`).
- **An activated power**: same, in `POWER_EFFECTS` keyed by power name, sourceId = the Pokémon in play (use THAT Pokémon's power); its `PokemonPowerType` goes in `ACTIVATED_POWER_TYPES`; `oncePerTurn` powers call `markPowerAsUsed`. A passive power is a check inside the engine that calls `isPowerActive`.
- **An attack choice** (the attacker or the opponent picks something after the attack): make the effect data recognised by `isAttackChoiceEffect` and add its step (`stepFor`) and its effect (`applyChoice`) in `lib/attackChoices.ts`.
- **A special Energy**: card data (`provides`, `providesAllTypes`), and `SPECIAL_ENERGY_ATTACH_EFFECTS[name]` (board/special-energy.ts) for on-attach-from-hand effects (Knock Outs are checked after).
- **A "when you play it from your hand" power**: `PokemonPowerType.OnPlayFromHand` on the card and an `ON_PLAY_POWERS[powerName]` entry (`step` / `resolve`, lib/powerChoices.ts); the board actions and Pokémon Breeder trigger it.
- **A chosen-target attack** ("choose 1 of your opponent's Pokémon"): `ChooseTargetDamage` data (`targetScope`, `applyWeaknessResistance`, `switchWithDefender`, `suppressTargetPower`, `optionalEnergyDiscard`); the damage goes through `dealChosenTargetDamage` (PlusPower/Defender on the Active, Kabuto Armor, protection, Strikes Back, Mirror Shell, Destiny Bond, Final Beam).
- **A Stadium**: card data with `trainerType: TrainerType.Stadium` is enough (the AI judges it through the same hooks: `stadiumValue`; a leader Gym that favors an owner's Pokémon goes in `stadiumFavoredOwner`) — every Stadium without a TRAINER_EFFECTS entry is played with `playStadium` (effects/stadiums.ts: stays in `state.stadium` `{ card, playedBy }`, a new one sends the old one to the discard pile of whoever played it, never two with the same name). Continuous rules go in `domain/stadiums/rules.ts`, one hook each read by the engine (`stadiumRetreatModifier`, `stadiumIgnoresResistance`, `stadiumBenchLimit`, `stadiumExtraTrainerDiscards`); only that file and effects/stadiums.ts name Stadium cards. A Stadium with an on-play effect gets a `STADIUM_EFFECTS` entry that wraps `playStadium`. A Stadium the player whose turn it is may use (Celadon City Gym) gets a `STADIUM_ACTIONS` entry (`CardEffectDef`, sourceId = the Stadium card id), run by `getStadiumActions` / `canUseStadiumAction` / `getStadiumActionCoinFlips` / `getStadiumActionSteps` / `useStadiumAction` (same flow as Trainers / powers; AI action `useStadium`). Gym Challenge hooks: `resistanceAmount` / `stadiumIgnoresWeakness` (every W/R site, AI estimates included), `stadiumEvolutionHeal` (inside `evolvePokemonInPlay`, so every evolution path), `getPlayBasicCoinFlips` + `playBasicPokemon(..., { coinResults })` (Minefield; Chaos Gym for Trainers played as Basics). Chaos Gym runs through the generic Trainer entry points (effects/index.ts): coin first (`isChaosGymCoinPending`), heads → `pendingChaosGymPlay`, tails → `pendingChaosOffer` answered by the other player and played on its own view out of turn (`trainerView` kind "offer").
- **A "play as a Basic" Trainer**: `playsAsBasic: { hp }` on the card data (same rules as Mysterious Fossil); it needs no TRAINER_EFFECTS entry (`isPlayedAsBasic`).

## TCG rules to respect (classic era)

- Damage order: base damage (incl. `Nx`/`N+` coin math and effect bonuses, next-turn bonus) → weakness ×2 → resistance −30 → PlusPower +10 each and Misty +20 for a Pokémon with Misty in its name (only if the attack does damage; `attackBonusFromModifiers`) → Defender −20 → next-turn reductions → barriers/protection → floor at 0. PlusPower is applied AFTER weakness/resistance.
- Asleep, Confused, Paralyzed replace each other; Poisoned stacks with them. Moving to the bench (retreat, switch) removes ALL special conditions, including Poison.
- Only Asleep, Confused and Paralyzed stop Pokémon Powers; Poison does not.
- Confusion: tails on the attack flip → 20 damage to itself. Sleep: flip between turns, heads wakes. Paralysis: wears off after the owner's next turn. Poison: 10 between turns (20 for Toxic).
- Knockouts must be checked after every damage source, including bench damage and between-turns damage.
- Double Colorless Energy counts as 2 colorless. Leek Slap–style attacks ("can't use this attack again as long as this Pokémon stays in play", incl. benching) are tracked on the Pokémon in play.
